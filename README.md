## 特殊权限提示！！！！
 因为Android 10+（包括16）出于隐私安全考虑，系统级限制了普通应用获取其他设备MAC地址的能力。这是Google的强制限制，无法通过代码绕过。<br>
 所以软件会索要root权限，当然你也可以拒绝，这不影响您使用软件，只是会获取不到MAC地址，Android 10+以下版本不会索要权限。
